# Changelog

## 1.0.0

- Ticket sidebar app: lists the ticket's attachments and converts the one you pick with Converter
  Studio (formats from the API), with progress, then **Download** and **Open**.
- The API key is a secure setting, sent by Zendesk's proxy to converter.studio only.
- "Most credits one conversion may use" (10 by default): dearer conversions are refused uncharged.
- Accounts whose attachment links need a sign-in: found out before anything is charged, and the
  agent can choose the saved file instead.
- Light and dark mode.
